
## Dataset

This project uses the **E-Commerce Sales and Customer Analytics** dataset available on Kaggle.

The dataset contains e-commerce-related data used for customer analysis and business insights.

**Dataset Source:**  
[Kaggle – E-Commerce Sales and Customer Analytics](https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics)

### Download Instructions

The dataset is not included in this repository because of GitHub file size limitations.

Follow these steps to download it:

1. Visit the [Kaggle Dataset](https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics).
2. Log in to your Kaggle account.
3. Click the **Download** button.
4. Extract the downloaded ZIP file.
5. Place the extracted dataset files inside the `data/` folder of this project.

### Dataset Directory Structure

After downloading, organize the files as follows:

```text
Project/
│
├── data/
│   └── [Extracted dataset files]
│
├── notebooks/
├── README.md
└── requirements.txt
```

### Important Notes

- The dataset is hosted externally on Kaggle and is not stored in this GitHub repository.
- Download the dataset before running the project notebooks.
- Ensure that the dataset files are placed in the appropriate directory.
- Refer to the Kaggle page for dataset details and updates.
